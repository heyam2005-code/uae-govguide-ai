# دليل تجهيز وتسليم النسخة النهائية — UAE GovGuide AI

**ملاحظة موعد:** الموعد المنشور للتسليم الأول هو 10 نوفمبر 2026. تحققي من قناة تسليم الرابط الخاصة بفريقكم (بريد المنظمين/منصة المسابقة)؛ إنشاء GitHub وحده لا يُعد تسليمًا تلقائيًا.

## 1. قبل التسليم
1. احفظي نسخة من مشروع V5.1، واستخدمي مجلد FINAL_SUBMISSION فقط للنشر.
2. شغّلي `python -m pytest tests -q` من داخل المجلد وتحققي من النتيجة.
3. افتحي `/assistant` وجرّبي السيناريو الأساسي: مواطن إماراتي 29، منطقة البرشاء في دبي، الهوية شهر، الجواز 12، صورة نعم، الخدمة عاجلة. ينبغي أن تظهر توصية البرشاء مفسّرة مع التنبيه بعدم تأكيد الخدمة العاجلة.
4. اختبري الاستثناء: صلاحية الجواز شهر واحد؛ ينبغي منع تأكيد الجاهزية واقتراح الاستفسار عن المسار المجمّع عند انطباق الشروط.
5. لا تدخلي معلومات هوية حقيقية ولا تصوّري بيانات حقيقية بالفيديو.

## 2. GitHub — عبر المتصفح بدون Git CLI
1. افتحي https://github.com وسجلي الدخول.
2. اختاري **New repository** وسميه `uae-govguide-ai`، واجعليه **Public** إذا كانت قواعد المسابقة تسمح بفريقكم بذلك.
3. قبل الرفع افتحي مجلد FINAL_SUBMISSION وتأكدي أنه **لا يحتوي** `.env` أو `.venv` أو `__pycache__` أو سجلات المستخدمين.
4. في مستودع GitHub اختاري **Add file > Upload files**، واسحبي محتويات مجلد FINAL_SUBMISSION مع الحفاظ على المجلدات `app`, `data`, `docs`, `scripts`, `static`, `tests`, `artifacts`. بعض المتصفحات لا تحافظ على المجلدات عند رفع ملفات منفردة؛ تأكدي من شجرة الملفات بعد الرفع.
5. اضغطي **Commit changes**، ثم افتحي README وتأكدي أنه يظهر، وانسخي رابط المستودع.
6. اختبار أفضل: افتحي صفحة المستودع من نافذة خاصة (Incognito) للتأكد أن لجنة التحكيم تستطيع قراءته.

## 3. Technical Report
1. الملف `docs/Technical_Report_5_pages.pdf` مسودة جاهزة ذات خمس صفحات؛ **ليست القالب الرسمي**.
2. حمّلي قالب ITU من صفحة المسابقة الرسمية وانقلي أقسام مسودة `Technical_Report_EDITABLE.md` إلى حقول القالب.
3. أدخلي اسم الفريق وأسماء الأعضاء ورابط GitHub النهائي في التقرير.
4. تحققي أنه لا يتجاوز 5 صفحات وأن روابط المراجع تعمل.
5. لا تكتبي أن النموذج السحابي مفعّل إذا ما تم تفعيله واختباره.

## 4. Knowledge Base
في `data` توجد الخدمات والسياسات والاستراتيجيات والمصادر والمراكز ومقاطع المعرفة RAG. أرفقي `UAE_GovGuide_AI_KNOWLEDGE_BASE.zip` عند وجود خانة مستقلة لقاعدة المعرفة أو قدّمي مسار `data/` في GitHub. اذكري أن البيانات منظّمة يدويًا من صفحات عامة وهي لقطة بتاريخ 9 نوفمبر.

## 5. فيديو العرض (اختياري للجولة الأولى)
صوّري 4-6 دقائق، بحد أقصى 7 دقائق: الهدف -> المعمارية -> الخدمة العادية -> الاستثناء -> التنبيه بالمركز -> سجل القرارات والمصادر -> حدود النموذج. راجعي `DEMO_SCRIPT_AR.md`.

## 6. قنوات التسليم
أرسلي فقط بعد التحقق من رابط أو قناة التسليم التي أعطاها المنظمون لفريقكم. المواد الأساسية: ملف التقرير ضمن القالب، رابط GitHub، قاعدة المعرفة؛ الفيديو اختياري الآن حسب الصفحة الرسمية.

## 7. ما يحتاج مراجعة بشرية قبل الادعاء بالاكتمال
- موافقة الفريق على نشر الكود والبيانات؛ جميع الأسماء وروابط المستودعات النهائية.
- الرسوم والصفحات الحكومية قد تتغير؛ اذكري تاريخ آخر تحقق.
- المراكز ليست مرتبة حسب مسافة فعلية ولا يوجد تحقق لحظي من الخدمة العاجلة.
- نتائج الاختبارات اصطناعية صغيرة؛ لا تقدميها كنسبة دقة عامة.
- لا يوجد تشغيل سحابي مؤكّد أو مصادقة حكومية رسمية في هذه النسخة.
